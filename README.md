# Personal Portfolio Website

Welcome to the repository of my personal portfolio website. This site
serves as a digital space to showcase my projects, skills, and professional
journey as a developer.

## Technical Specifications

- **Design Framework:** Responsive layout adapted for mobile, tablet,
  and desktop viewports.
- **Architecture:** Component-based structure with separated sections.
- **Data Presentation:** Project and skill sections updated dynamically.
- **Build System:** Bundled utilizing Vite and managed with pnpm.

## Tech Stack & Tools

- **Core Languages:** HTML5, CSS3, TypeScript
- **Frontend Framework:** Vanilla
- **Build Tool:** Vite
- **Package Manager:** pnpm
- **Styling:** CSS Modules
- **Deployment:** GitHub Pages

## Project Structure

An overview of the directory organization:

- `src/components/` - Reusable UI elements (Navbar, Footer, ProjectCard).
- `src/sections/` - Main page sections (Hero, About, Projects, Contact).
- `src/assets/` - Images, icons, and static resources.

## Local Development

To run this project locally, execute the following commands in your terminal:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/xennava/portfolio.git
   ```

2. **Install dependencies:**

   ```bash
   pnpm install
   ```

3. **Start the development server:**

   ```bash
   pnpm dev
   ```

4. **Build for production:**

   ```bash
   pnpm build
   ```
